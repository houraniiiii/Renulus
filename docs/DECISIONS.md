# Renulus decisions

Recorded: 2026-10-04. This record distinguishes user choices from dated evidence
and work that has not been decided.

## Confirmed choices

| Subject | Decision |
| --- | --- |
| Identity | Renulus; an independent open-source project. |
| Repository | `houraniiiii/Renulus`, with independent history beginning at bootstrap commit `8917ce4`. Its sole remote is `origin`. |
| Audience | Doctors during nephrology specialisation. |
| Purpose | A complete learning application for understanding, practice and examination preparation. |
| Models | Use existing models; no retraining or fine-tuning. |
| Brand | C — Renal flow, with the selected teal treatment; modern medical, calm, precise and approachable, with a subtle renal reference. |
| Separation | Preserve the inherited clinical MVP and batch/research project outside the active repository. The desktop launcher opens that baseline explicitly as a reference. |
| Current scope | Cleanup and selective preservation only. No new research, product planning or prototype is authorised by this cleanup. |

## Unresolved work

Product research and design are pending. Detailed learning journeys, navigation,
application architecture and model/provider choices have not been selected for
this project. Earlier module proposals, UI studies and clinical MVP choices do
not become Renulus requirements through preservation.

The application licence has not been selected. Preserved development tooling
retains its own licences, recorded in [third-party notices](../THIRD_PARTY_NOTICES.md).

Content selection and operation-specific use eligibility remain review-needed.
No acquired teaching corpus, validated assessment set, educational-effectiveness
result or clinical-performance result is established by this cleanup.
