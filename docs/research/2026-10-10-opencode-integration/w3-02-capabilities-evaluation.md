**Proposed schema semantics.** Configuration contains `schemaVersion=1`, immutable `revision`, `selectedConnectionId`, and connection descriptors with `endpoint`, `protocol`, `credentialRef`, `modelAliases`, `defaultModelId`. Null selectedConnectionId means disconnected; null defaultModelId means Automatic. `roles[purpose]` contains `mode=inherit|override|disabled`, optional `modelId`, `contextProfile`, `outputTokens`, and `attemptLimit`. Purpose is a trusted enum, including current producer strings; unknown fields/purposes are rejected. Missing roles normalise to inherit except title; override requires modelId, other modes prohibit it. Disabled wins over overrides. Initial contextProfile is standard; proposed output reservation is 4,096, capped by route evidence. Budgets are positive; initially one attempt per stage, no automatic repair/substitution/resend, with bounded workflow totals. Questions initially use validated JSON text; native schema enforcement is a separately evidenced option, not a prerequisite. Persist resolved route/configuration and credential epoch per attempt. Activation is transactional; existing sessions require explicit migration, while current revocations always narrow access. [S1](../../planning/opencode-v2/specs/01-harness-control.md), [S3](../../planning/opencode-v2/specs/03-workflows-migration.md).

**401 lifecycle.** Separate documented support, route access and observed capability evidence. Store `observed=unknown|pass|reject`, timestamp, receipt and feature-specific limits. Key observations by connection/account epoch, endpoint/protocol, model alias/deployment and adapter version; changes stale prior observations. On 401, retain documentation but mark effective access/capabilities unknown, require reconnection, invalidate pending permits and prevent retry across that connection. Keep unaffected connections usable. Reconnection creates a new credential epoch with unknown observations; catalogue success proves no vision/tools/schema/window. Only a deliberately authorised successful operation promotes the features actually exercised. Image rejection narrows image support; quota/timeout does not prove missing vision. This closes the reproduced [manager status gap](../../../runtime/renulus/runtime/manager.py) and [existing 401 expectation](../../../tests/runtime/test_images_context.py); stored credentials currently restore “available” after observations clear.
