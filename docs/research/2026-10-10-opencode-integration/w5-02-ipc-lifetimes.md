1. **H01: reconnect-safe requests and control capacity.** Bind every request/reply to protocol version, profile/store identity, process-start generation, logical operation/attempt and unique request ID. Reject replies from an earlier process generation even when logical IDs match. Negotiate maximum frame bytes and in-flight requests; reject overload before admission. Define rejection before admission, accepted/pending, committed-reference, cancelled/settled and uncertain-after-disconnect outcomes. Timeout ends observation; it must not authorize redispatch. Reserve bounded transport capacity for cancellation, policy updates and settlement replies; the receive loop must dispatch handlers without waiting for their completion. Test a saturated data queue and a lost commit acknowledgement. These details are absent from H01’s current ownership/readiness AC. Current observation drops old entries from a 64-item queue; IPC command replies cannot inherit that loss policy. Source: `76cfdff:runtime/renulus/learn/conversation_stream.py:35–54`.

2. **H05: move answer resolution outside transactions.** `MemoryRepository.material()`, `current()` and `commit_capture()` resolve ordinary answer text inside `BEGIN IMMEDIATE` transactions. Replacing the local resolver with an RPC there could create Python-write-lock → host-resolution → Python-policy-check → same-lock waiting. This is an inferred integration deadlock, not an executed current deadlock. Resolve immutable, digest-bound answer bytes outside all canonical transactions; revalidate the local publication receipt, dependencies, policy and tombstones inside commit. Prohibit *all* cross-process waits while holding canonical transactions or conversation/case/recovery thread locks. Use a logical admission lease across the larger operation; acquire physical locks only for local validation/commit. Drain remote work before acquiring recovery’s engine locks, so its final callbacks can still complete. Sources: `76cfdff:runtime/renulus/memory/repository.py:232–305,455–536`, `76cfdff:runtime/renulus/memory/study_answers.py:11–55`, and `runtime/renulus/storage/database.py:51–64`.

   Current extraction runs through `asyncio.to_thread`; `ApprovedLLM` submits generation back to the event loop and waits up to 120 seconds. Preserve that worker placement and keep the event loop/IPC pump available. Admission must follow committed evidence, return without waiting for extraction, and retain one capture-job/attempt identity; extraction output must never enqueue itself. Test this round trip with one host execution slot. Sources: `76cfdff:runtime/renulus/memory/service.py:160–227`, `runtime/renulus/memory/providers.py:63–104`.

3. **H01/H05/H18: settle actual workers before releasing stores.** An executed controlled-engine probe called `MemoryService.start()`, paused extraction, then awaited `close()` with a two-second bound. Result: `close_returned=true, extract_thread_still_running=true, active_runs=0, recovery_guard_admitted=true, provider_cancel_requested=true, job_state=running, canonical_facts=0`. Releasing the thread finished cleanup; late facts remained zero. This establishes a lifetime gap; it does not establish corruption or a normal UI restore after shutdown. Sources: `76cfdff:runtime/renulus/memory/service.py:52–65,205–227,346–358`; controlled fixtures in `tests/memory/test_service.py:19–74`.

   Add an outstanding-worker lease that survives coroutine cancellation until extraction/finalizers finish. Timeout must leave recovery/owner handoff blocked or explicitly uncertain. Close admission, request cancellation, keep IPC replies available through bounded drain, then release engines/stores. Upstream [interrupt acceptance and settlement](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/core/src/session/execution.ts#L23-L39) are already separate; Python must supply its own settlement evidence.

4. **H06: specify Save’s crash states.** Current promotion checks active production and copies volatile history within one canonical transaction under attachment/conversation/case locks, rolling back attachment promotion on failure. Passing current tests establish that boundary. Source: `76cfdff:runtime/renulus/learn/conversation_repository.py:405–459`. The new two-store transfer needs a promotion ID and explicit states: freeze family admission; settle descendants; stage an immutable family manifest/attachments in a non-admitted persistent destination; atomically commit canonical mapping; activate destination; retire volatile source. Recheck policy/context/deletion before mapping and activation. Replay reconciles these states without generation. Inject crashes at every transition, including after mapping but before acknowledgement. Failed promotion retains volatile originals only while their process survives; hard process death cannot preserve RAM. Orphaned persistent staging needs deterministic cleanup before recovery/export. H06 currently promises “one mapping” without this crash contract.

5. **H02/H06/H07: preserve currentTest/Study revocation across IPC.** Carry canonical policy/context epochs plus Study’s attempt/item/version/draft revision and exposure kind. Validate replies before disclosure and rebind the publication guard before domain execution/commit, including detached callbacks. The existing guard is a Python `ContextVar`; it does not travel over IPC. Starting then finishing a Test must still invalidate an older revision. Keep neutral status/Stop accessible while assistance is blocked. Sources: `76cfdff:runtime/renulus/storage/publication.py:8–23`, `runtime/renulus/assessment/attempt_repository.py:499–512`, `runtime/renulus/server.py:132–169`.
