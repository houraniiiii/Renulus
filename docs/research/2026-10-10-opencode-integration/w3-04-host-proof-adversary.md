**Dependency wiring is preserved; the concrete composition is unproved.** `node.replace(node.mapLayer(...))` preserves dependency declarations and requires the same output/error/environment contract. Acquiring the original layer, then returning its decorated service, avoids inventing dependencies; retain scope/finalizers and typed failures. However, replacement lookup uses node identity and later entries win: decorating a declaration does not decorate an earlier configured replacement. Use closure-held policy state, not a location-service dependency in a global node. Consolidate replacements against the exact cohort; simulation replacements can supersede caller overrides. No concrete decorator has been typechecked here. **Generate denial requires the global LLM replacement.** Stateless `Generate.text` is actually a location service: it resolves a model and calls `llm.generate` without session preparation; its invented session header supplies no authorization. Session generation captures LLM before entering the selected instance. Wrap `stream`, `generate` and both `compact` forms: original `generate` closes over its original stream. Default-deny absent/stale trusted admission, including plugin bootstrap calls. Preserve final HTTP/WS enforcement from W2; successful denial across those boundaries remains unexecuted. **Recovery can wait without blocking construction, but reopening the gate is unsafe by default.** The host acquires services, registers plugins, then forks recovery. Wrap the returned recovery effect with an interruptible wait; never wait during layer acquisition. This permits fresh unrelated sessions while the entire sweep waits, provided ordinary admission does not depend on that sweep. Fence direct access to held sessions too. The sweep has no per-session defer argument; zero attempts or downstream denial can terminalize claims. [Host](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/sdk/src/internal/host.ts#L50-L70) · [sweep](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/core/src/session/execution/restart.ts#L77-L231)

A new counterexample matters: recovery snapshots active executions but passes only recoverable background-child IDs to `releaseChildClaims`. That SQL clears every other suspended child, including a newly active foreground child. **Executed SQL translation:** four synthetic rows confirmed that both a live foreground child and an orphan lose their claims, while a listed recoverable child and top-level parent retain theirs. This proves predicate behavior, not an executed OpenCode race. Opening delayed recovery therefore needs admission quiescence or narrowly verified ownership/eligibility filtering. Selective deferral must also cover background notifications and child cleanup, not just `listSuspended`. [Cleanup predicate](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/core/src/session/store.ts#L194-L250)

**Temporary sessions need another database/runtime graph.** Selected instances inherit the global replacements and share their database; metadata/key/location is not a retention switch. The smallest proposed composition is a separate `:memory:` EmbeddedHost, potentially inside the same managed process, for temporary sessions and their descendants. Do not place them in the persistent profile host and delete afterwards. This preserves the current Renulus volatile semantics. [Instance inheritance](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/sdk/src/internal/instances.ts#L65-L103) · [database ownership](https://github.com/anomalyco/opencode/blob/4b6fea2875e4f2e3e8a8fee181803e54f7056845/packages/core/src/database/database.ts#L55-L122)

An in-memory database alone is insufficient. Oversized tool results write their full text under `Global.data/tool-output`, with seven-day retention. Temporary output/attachments need volatile implementations. Module-level XDG roots and `Flock.setGlobal` precede service overrides: set owned process roots before imports, explicitly replace all Global paths, disable discovery/catalog fetching, and audit residual accesses. Windows database protection relies on inherited directory ACLs. SDK logging emits nothing without a writer; a supplied writer receives attributes/causes and needs an allowlist. Enabling it adds historical event data. Whole-session removal interrupts/settles execution, recursively removes children and removes its event aggregate. Revert deletes message/inbox suffixes without deleting retained event payloads; it is not scoped erasure. Test message projections, compaction payloads, copied history, spill files, WAL and backups independently. A narrow transactional erasure seam is conditional work if existing operations cannot meet S2; prompt filtering cannot substitute.
