**Review 09 — exact generation routes and authentication**

2026-10-10. Research only. Renulus baseline: `528025ff0b22477c12ee1512e0e7d15297a6e888`; Hermes bundled `af90026aa09949579bd423d24def3d38f743cde0` and inspected upstream `dce1e9b37581dd62e480a9064dc04a709c2940d3`; Pi v1.1.0 `abe508e1b89912adde45528136c3221eb69acdd7`; OpenCode v2 `55dde8810d8a859c0a21e42491ae7d5801fb49ef` ([source version 2.0.26][oc-version], distinct from the supplied public/default 1.18.35 baseline). Links use immutable commits and **raw-file line numbers**. Sources were read; no login, provider calls, installs or runtime tests were performed.

**Conclusion — judgment:** Pi's embedded agent-core offers the clearest starting point for this particular control requirement: inject Renulus's generation broker into every parent and child, retaining its domain adapters. Borrow OpenCode's purpose-specific request/retry hooks. Hermes remains usable, but adopting its full agent loop requires controlling several independent routing/recovery paths. This is a route-control conclusion, not an overall foundation selection or permission to migrate.

**Policy scope.** The [October 6 decision][r-decisions] requires actual authentication, quota, model and image rejections to remain visible without automatic retries, model fallback or subscription changes. The [October 5 handover][r-old] recorded failed quota checks, paused Go learning and no fallback/credential borrowing; [October 7][r-go] superseded that Go pause. These records leave transient-network and process-restart policies unresolved. The [current adapter][r-transport] disables SDK retries. Token refresh must not become an automatic resend after rejected generation. For adoption proofs, keep **all automatic generation retries/replay/fallback off**; any broader transient-network or restart policy is a proposal. Automatic initial model choice inside the selected subscription is distinct from changing routes after failure.

Four load-bearing findings:

1. **Renulus already has reusable enforcement assets.** Its [allowlist and endpoints][r-policy] bind Codex to `gpt-6.1-sol`, `gpt-6-astra`, `gpt-6-luna` and Go to `mimo-v2.6-pro`, `deepseek-v4.1-flash`. [The transport][r-transport] validates the wire model, takes explicit credentials/endpoint, disables environment proxy discovery and SDK retries, and accepts an injected HTTP transport. [Compression][r-summary] bypasses Hermes's auxiliary resolver; [Mem0 extraction][r-memory] calls the scoped application provider. Stock Hermes child/tool compliance does not follow. The existing transport disables tools, so it needs a reviewed tool-capable interface before serving a full harness.

2. **Hermes controls are distributed.** The bundled [main-client factory][h-sdk] defaults SDK retries to zero, but [agent initialization][h-recovery] defaults to three outer attempts and five additional recovery cycles. [Auxiliary routing][h-aux-route] can consult task/main fallback chains, and [auxiliary retries][h-aux-retry] default to two; its client construction is separate from the primary factory. The router correctly [refuses ambient provider guessing once a main provider is selected][h-discovery], also present in [inspected upstream][h-upstream]; this limits, but does not eliminate, route drift. The [fast-model fallback table][h-fast] contains Go `glm-5`, outside Renulus's list; [fast selection is opt-in][h-fast-opt]. [Children][h-child] can inherit fallback chains or own explicit overrides. Startup has [ambient configuration/credential resolution][h-startup]; [Mem0 OSS builds independent LLM/embedder configuration][h-mem0]. **Integration blocker:** explicit parent credentials alone do not govern every generative call. Disable these ladders and validate actual dispatch through a common broker; a single replaced primary client is insufficient.

3. **Pi has useful injection seams, with SDK/CLI qualifications.** [Agent-core accepts `streamFn`][pi-agent]; coding-agent [compaction][pi-summary] and [branch summaries][pi-branch] receive that same stream function. The Responses adapter accepts [injected fetch][pi-fetch]. Its [`openai` provider][pi-openai] includes subscription OAuth to `api.openai.com/v1`; [legacy `openai-codex`][pi-legacy] is a different route. [Go][pi-go] accepts stored/environment keys; none of this proves account entitlement. Stock [SDK initialization][pi-init] reads auth/models/settings/resources, [startup selection][pi-select] can choose another available provider, and [environment lookup][pi-env] falls through to process credentials even with empty scoped overrides. [Session retries][pi-retry] default on; [provider retries][pi-provider-retry] default zero. [Cache warming][pi-warm] makes extra generation requests outside the session stream wrapper. Disable warming and recovery (including overflow replay), isolate configuration/auth, and enforce model/endpoint/auth provenance at dispatch. The [subagent example][pi-child] spawns another CLI with its own model/configuration path; it does not inherit an injected in-process broker. Use host-created controlled children for the proof.

4. **OpenCode v2 has broad hooks but additional automatic routes.** [Request preparation][oc-hooks] covers primary, compaction, generate and title flows; [retry decisions][oc-retry] are mutable by hooks. [Embedded hosting][oc-host] permits layer replacements. Nevertheless, [title selection][oc-title-select] prefers an auxiliary/small model and [title generation][oc-title-fallback] retries with the primary model after failure. [Compaction][oc-summary-model] can select another agent model; [template repair][oc-summary-repair] makes a second request outside the ordinary retry decision. [Child overrides][oc-child] also need validation. [Global/project discovery][oc-config] and [environment connections][oc-env] are ambient inputs. Direct ChatGPT token sharing [filters a broad model set and forces summary compaction][oc-auth]; catalogue filtering alone is not subscription/model enforcement. **Integration blocker:** a retry-denying hook is insufficient; disable title fallback, compaction repair and transport continuation/replay, validate final API model IDs and credentials, and replace/contain ambient configuration. [Restart recovery][oc-restart] automatically resumes orphaned work with at-least-once semantics; adopting that behavior requires a separate policy, not an inference from October 6.

**Project tradeoff and remaining evidence.** Preserve Mem0 OSS, Docling/HybridChunker, FastEmbed, LanceDB and canonical SQLite. Bundled CPU embeddings/OCR are the [confirmed narrow exception][r-exception], not permission for a local generative summarizer; a harness “small model” still consumes the selected subscription. Keep learner/source/assessment authority outside transcripts and derived indexes. Proposed broker inputs should include purpose, root/child identity, selected subscription, exact API model, fixed endpoint and auth provenance, with visible terminal rejections. Plugins/tools making independent generative HTTP calls remain an escape path: extension trust and outbound control need explicit design. Offline synthetic proofs should reject forbidden IDs, endpoints, ambient keys and second attempts across parents, children, summaries and memory extraction. Evidence that all paths share one enforced dispatch boundary would change the conclusion; uncontainable Pi extension/child routing would weaken it. No account-capability or educational-quality claim follows from this inspection.

**Handoff:** `docs/research/2026-10-10-harness-adoption/review-09-route-control-authentication.md`. Conclusion: prefer embedded Pi for route-control evaluation. Strongest fact: its main loop and built-in summaries accept the same stream seam. Unresolved risk: autonomous extensions/subprocess children and restart replay can escape host policy.
