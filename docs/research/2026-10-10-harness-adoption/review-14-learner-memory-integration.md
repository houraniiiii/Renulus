# Review 14: learner memory across harness foundations

**Conclusion (judgment):** Keep the scoped SQLite/Mem0/Qdrant/FastEmbed module as Renulus domain infrastructure. Hermes offers direct Python reuse; Pi and OpenCode can consume the same service through tools and hooks. Memory integration alone does not select an overall foundation. Stock transcript capture should not become learner-record authority.

October 10, 2026; source inspection only. Baselines: Renulus `528025ff0b22477c12ee1512e0e7d15297a6e888`; bundled Hermes `af90026aa09949579bd423d24def3d38f743cde0`; inspected upstream Hermes `dce1e9b37581dd62e480a9064dc04a709c2940d3`; Pi 1.1.0 `abe508e1b89912adde45528136c3221eb69acdd7`; OpenCode v2 source 2.0.26 `55dde8810d8a859c0a21e42491ae7d5801fb49ef`. These source identities do not establish published-artifact equivalence or tested behavior. No engines, providers or applications were executed.

Five load-bearing verified facts:

1. **Capture consumes classified evidence.** Renulus reads producer classification before text, rejects case/unclassified scope, and checks original ownership. Study-answer capture resolves a completed assistant reply by run/message IDs and SHA-256; reviewed-assessment and interest observations need no inference. The outbox records evidence IDs/fingerprints, then rechecks scope, suppression and cancellation inside the commit transaction. General-point extraction uses a fresh transient Mem0 index and the approved subscription seam; persistent indexing uses `infer=False`. Sources: [repository.py:169–260][r-material], [study_answers.py:11–55][r-answer], [repository.py:308–333][r-commit], [engine.py:156–186][r-engine-ops], [providers.py:63–97][r-provider].

2. **Correction and recall preserve canonical authority.** Expected revisions guard edits/deletes; either action suppresses every linked source key and cancels its unfinished jobs. Delete also records a tombstone. Rebuild indexes canonical rows, removes derivative Mem0 history/messages, and publishes a generation only if the SQLite epoch remains unchanged. Recall maps engine IDs to current canonical revisions, checks deletion/topic/budget, and returns canonical text. Cleanup can report `purge_pending`; corrected canonical history persists until separately purged. These are substantive domain rules. Sources: [repository.py:111–167][r-correction], [service.py:74–104][r-purge], [service.py:233–310][r-recall].

3. **Hermes lifecycle is useful; stock Mem0 sync has different semantics.** Bundled and relocated plugins send user/assistant turn text to extraction, truncate each message to a default 450 characters, and can skip ingestion when a previous sync remains busy. Recall is user-wide across agents and formats engine-returned memory text. Neither sync path enforces Renulus producer eligibility or correction suppression. For Renulus, that risks retaining case details/model assertions and losing qualifiers through truncation (inference). Sources: [bundled limits:36–43][h-cap], [bundled plugin:244–322][h-stock], [external plugin:36–43][m-cap], [external plugin:248–326][m-sync]. Current Hermes provides profile/session, prefetch, tool, shutdown and session-switch interfaces [memory_provider.py:103–174][h-interface]. Its catalogue relocates Mem0 to external revision `43849c6e9d4d773b83a8144b6373aedc67241a5d`, plugin 1.3.0 [catalogue:1–11][h-catalogue]. **Compatibility inference:** changing the import path alone would fail: Renulus's replacement constructor sets only `_memory`, whereas external add/search now require `_lock` and `_closed` [engine.py:67–82,138–150][r-constructor], [external backend:287–322][m-backend].

4. **Pi offers two distinct integration surfaces.** AgentSession extensions expose custom tools and context transforms; `agent_settled` distinguishes final settlement from `agent_end`. Cross-session domain data belongs in external storage [extensions.md:54–83,113–146,224–234][p-extension]. A proposed adapter can recall through those hooks and notify the existing outbox after a domain commit. Separately, `packages/durable` documents committed admission, typed documents and durable tasks [README:71–85][p-durable]. Its tool implementation commits intent before execution, defaults replay to unsafe, and resumes only when both stored and current policies say safe [tool.ts:85–110][p-replay]. Borrow that replay distinction; it cannot atomically coordinate an external Python/SQLite mutation by itself. The library explicitly labels its API experimental and changing without notice [README:1–7][p-experimental].

5. **OpenCode v2 has sufficient extension contracts.** Tool transforms add operations; before/after hooks carry session, agent and call identity. Session context exposes mutable system/messages plus request kind and retry controls [tool.ts:8–59][o-tool], [session.ts:25–67,127–171][o-session]. Proposed memory tools can call the same Python service, with context hooks injecting bounded recall. The inspected embedded SDK registers plugins before restart recovery and defaults its session database to memory [host.ts:30–56][o-host]; that is distinct from Renulus's canonical database. These contracts were inspected, not ported or exercised.

**Recommended boundary (proposal):** Renulus owns capture eligibility, evidence fingerprints, fact revisions, suppression, deletion reconciliation and assessment/source authority. Learner recall remains data rather than scientific evidence, matching [Learn:296–310][r-learn]. Runtime contributions are session identity, cancellation, lifecycle cleanup, tool dispatch, bounded context and durable admission. Keep one app-managed local Windows memory service/Qdrant owner; subagents submit candidate evidence through it. Expose recall and deliberate edits/deletes with host-derived scope, revision guards and idempotency; automatic capture follows committed domain evidence. Saved-by-default chats change transcript retention, not case-to-memory eligibility [decisions:23][r-retention].

**Policy and uncertainty:** October 6's exact rule keeps authentication, quota, model and image rejections visible without automatic retries/fallback/subscription changes [decisions:142–152][r-policy]. The current adapter disables SDK retries broadly [adapter:104–113][r-adapter]; retain that conservative adoption-proof baseline. Transient-network retries and process-restart inference require separate proposals: Renulus already requeues interrupted running jobs [repository:12–16][r-restart], which differs from retrying a known rejection. Canonical idempotency does not prevent repeated provider work.

Canonical deduplication currently compares normalized text plus kind/topic [repository:70–89][r-dedup]; it does not establish semantic consolidation. Suppression covers linked evidence, not every future paraphrase. Evidence that could change this recommendation: Windows proofs of concurrent correction/deletion during capture/recall, crash replay without duplicate generation or resurrected facts, temporary/saved case isolation, and accurate extraction across varied nephrology domains. Whole-index rebuild cost and external-plugin compatibility remain unmeasured; scope labels and extraction prompts do not establish patient-data detection or educational accuracy.
