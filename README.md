# Renulus

Renulus is an independent open-source learning project for doctors training in
nephrology. The intended deliverable is a complete application that helps trainees
understand the subject, practise applying their knowledge and prepare for
examinations, using existing models without retraining or fine-tuning.

This repository contains the confirmed direction, selected brand, development
tooling and a small set of dated references. Product research, design and
application implementation are pending. The current work is workspace cleanup.

The repository is `houraniiiii/Renulus`, with independent Git history. A separate
desktop launcher opens the archived clinical MVP as a reference. That inherited
application does not demonstrate the intended Renulus learning product.
